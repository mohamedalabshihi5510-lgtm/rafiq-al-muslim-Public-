# رفيق المسلم — مشروع أندرويد تأسيسي

هذا مشروع أندرويد أصلي بلغة Kotlin وواجهات Jetpack Compose، ومعه سير عمل GitHub Actions لبناء APK سحابيًا.

## مهم جدًا
هذه **نسخة تأسيسية مبكرة وليست التطبيق النهائي**. الشاشة والانتقال بين الأقسام والسبحة التفاعلية تعمل داخل التطبيق، لكن لم يتم بعد ربط:
- حساب مواقيت الصلاة بالموقع وطريقة الحساب.
- تنبيهات الأذان الدقيقة وخدمة التشغيل في الخلفية وإعادة الجدولة بعد إعادة التشغيل.
- نص المصحف المعتمد والتلاوات الصوتية والتنزيل دون إنترنت.
- بث إذاعة قرآن موثوق ومشغل صوت بالخلفية.
- مكتبة الأذكار الكاملة والتشغيل الصوتي وجدولة كل 10 دقائق.
يجب استكمال هذه الوظائف واختبارها قبل اعتبار التطبيق جاهزًا للاستخدام اليومي أو النشر.

## رفع المشروع من هاتف أندرويد
1. نزّل ملف ZIP وافتح GitHub في المتصفح.
2. أنشئ مستودعًا جديدًا باسم `rafiq-al-muslim` واجعله Private أو Public حسب رغبتك.
3. اختر Add file ثم Upload files.
4. فك ضغط الملف على الهاتف أولًا، ثم ارفع **محتويات المجلد** إلى جذر المستودع، وليس ملف ZIP نفسه.
5. اضغط Commit changes وانتظر ظهور تبويب Actions.
6. افتح عملية `Build Rafiq Al-Muslim APK`. عند نجاحها افتح تفاصيل العملية، ثم نزّل Artifact باسم `rafiq-al-muslim-debug-apk`.
7. فك ضغط الـ Artifact وثبّت `app-debug.apk`. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## متطلبات البناء
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- JDK 17
- Android SDK Platform 36

ملف APK الناتج هنا نسخة Debug للاختبار فقط، وليس إصدار متجر Google Play موقّعًا بمفتاح إصدار.
